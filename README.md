# Arna Tours & Travels - Automation & Manual Testing Project

## 📌 Project Overview
This repository contains the **Automation and Manual Testing framework** developed for **Arna Tours & Travels**, a travel booking and management system.  
The project focuses on ensuring the reliability, accuracy, and efficiency of the application through both **manual test cases** and **automated scripts**.

## 🎯 Objectives
- Validate core functionalities of the travel booking platform.
- Ensure smooth user experience across modules like **search, booking, payment, and cancellation**.
- Automate repetitive test scenarios to save time and improve accuracy.
- Provide detailed documentation of manual test cases for regression and exploratory testing.

## 🛠️ Tech Stack
- **Automation Tool:** Selenium WebDriver  
- **Programming Language:** Java  
- **Build Tool:** Maven  
- **Testing Framework:** TestNG  
- **Manual Testing:** Test cases documented in Excel/Sheets with detailed steps, expected results, and actual outcomes.

## 📂 Repository Structure
```
├── AutomationScripts/        # Selenium + TestNG scripts
├── ManualTestCases/          # Documented manual test cases
├── Reports/                  # Test execution reports
├── Screenshots/              # Evidence of test runs
└── README.md                 # Project documentation
```

## ✅ Features Tested
- User login & authentication  
- Search for tours & packages  
- Booking flow (single & multiple travelers)  
- Payment gateway integration  
- Booking cancellation & refund process  
- Admin panel functionalities  

## 🚀 How to Run Automation Tests
1. Clone the repository:
   ```bash
   git clone https://github.com/vaishnavibhatakhande-cmd/Arna-Tours-Travels-Automation-Manual-Testing-project.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Arna-Tours-Travels-Automation-Manual-Testing-project
   ```
3. Install dependencies using Maven:
   ```bash
   mvn clean install
   ```
4. Run the test suite:
   ```bash
   mvn test
   ```
